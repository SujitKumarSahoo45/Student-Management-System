# Student Management System

A web-based Student Management System developed using Java, JSP, Servlets, JDBC, and MySQL. This application allows users to manage student records efficiently through a user-friendly interface.

## Features

* User Registration
* User Login Authentication
* Add Student
* View Student Records
* Update Student Information
* Delete Student Records
* Session Management
* Responsive User Interface

## Technologies Used

* Java
* JSP
* Servlets
* JDBC
* MySQL
* HTML
* CSS
* Apache Tomcat

## Project Structure

* JSP Pages (Frontend)
* Servlets (Controller)
* JDBC (Database Connectivity)
* MySQL Database

## Setup Instructions

1. Clone the repository.
2. Import the project into Eclipse/STS.
3. Configure MySQL database.
4. Update database credentials in DBConnection.java.
5. Deploy the project on Apache Tomcat.
6. Run the application.
